# Testosterone Health Guide

A responsive, interactive educational website providing science-based information about testosterone health, exercise, nutrition, sleep, and healthy lifestyle habits.

## Live Website

[Visit Testosterone Health Guide](https://kharji1986-hub.github.io/testosterone-health-guide/)

## Technologies Used

- **HTML5** – Semantic page structure and accessible content
- **CSS3** – Responsive layouts, styling, and dark mode
- **JavaScript** – Interactive calculators, buttons, and DOM manipulation
- **GitHub Pages** – Website hosting and deployment

## Key Features

- BMI Calculator
- Daily Calorie Calculator
- Testosterone Unit Converter (ng/dL and nmol/L)
- Light and Dark Mode
- Responsive Navigation
- Educational Pages for Exercise, Nutrition, Sleep, and Supplements
- Testosterone Blood Test Information
- Interactive Frequently Asked Questions
- Scientific References and Medical Disclaimer

## Performance and Accessibility

The website was optimized for performance, accessibility, SEO, and mobile responsiveness.

During development, Google PageSpeed Insights reported scores of 100/100 across Performance, Accessibility, Best Practices, and SEO.

These scores reflect the tested version and may change over time.
